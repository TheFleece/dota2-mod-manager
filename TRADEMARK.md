# The name, the logo and the site

The code of this project is free software under GPL-3.0, and that will not change. Fork it,
change it, ship it, sell it. This file is about the things a licence does not hand over with the
code: the name, the logo, the site and the identity of the person behind it.

## What the licence gives you

Everything in `LICENSE`, plus the two additional terms in `NOTICE` under section 7, which ask for
credit rather than for permission. In short: keep the copyright line, keep the About notice the
app shows, carry the same credit wherever you offer your build (the readme, every release page,
any site an installer can be downloaded from), and say that your version is yours and changed,
with a date. Nothing in this file takes any of that away.

## What it does not give you

**The name.** "Dota 2 Mod Manager" is how this program is known to the people who use it, and
"TheFleece" is a person. A build that is not published by this project must not be presented under
either. Call it what you like, as long as somebody looking for this program does not find yours by
mistake, and as long as you do not suggest this project endorses or maintains it.

**The logo and the artwork.** `.github/banner.svg`, the application icon and the images on the
site are not covered by the code licence and are not yours to reuse. Draw your own.

**The domain and the channels.** `dota2modmanager.com`, the update feed, the Discord server and
the accounts that publish releases belong to this project. A fork publishes from its own.

**The impression that this is us.** You may not say your build is this one, sign or present it as
coming from this project, or use the name of this project or its maintainer to recommend yours.

## Why it is written like this

Two managers have already been built on this code. Both credit it, and one of them says so on its
own site and in its launch post. That is how it should work and it cost nobody anything, because
the rule is simple: take the code, leave the name.

The alternative, a licence that forbids competing builds, would make this program not open source.
It would cost the OSI-approved licence this project is checked against, the free code signing that
an OSI licence is a condition of, and the right of anybody to audit what runs on their machine.
None of that is worth trading for a restriction that would not stop a determined copy anyway.

So the line sits where it can actually be held: the code is everybody's, the name is not.

## If you think something crosses it

Write to the maintainer before anything else: a name that reads as ours, an installer that carries
our credit stripped out, or a page that presents a build as this one. Most of it is a
misunderstanding and ends in an edit. [MENTIONS.md](MENTIONS.md) lists the projects that build on
this one and what each of them credits, and that list is kept whether the news is good or not.
